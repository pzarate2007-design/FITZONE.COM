# 🏋️ FITZONE — Entrena. Mejora. Supera tus límites.

Plataforma web moderna de fitness y gimnasio desarrollada con HTML, CSS y JavaScript puro. Diseñada con una estética oscura tipo "neon" y enfocada en ofrecer una experiencia interactiva completa para atletas y entusiastas del fitness.

## 🌐 Sitio en Línea

👉 **[Ver sitio publicado](https://TU-USUARIO.github.io/fitzone/)**

## 📸 Descripción del Sitio

FITZONE es un sitio web completo que incluye las siguientes secciones:

### 🔹 Secciones Principales

| Sección | Descripción |
|---------|-------------|
| **Inicio (Hero)** | Presentación impactante con animaciones, estadísticas en tiempo real y llamadas a la acción. |
| **Entrenamientos** | Guías por grupo muscular (pecho, espalda, piernas, hombros, brazos, core) con ejercicios, series y consejos biomecánicos. |
| **Rutinas** | Planes de entrenamiento organizados por nivel: Principiante, Intermedio y Avanzado con rutinas semanales detalladas. |
| **Nutrición** | Información sobre macronutrientes, planes alimenticios para volumen, definición y mantenimiento. |
| **Herramientas** | Calculadoras interactivas: IMC, calorías diarias (TDEE), 1RM (repetición máxima) y distribución de macros. |
| **Progreso** | Sistema de registro de progreso personal con almacenamiento en el navegador (localStorage). |
| **Contacto** | Formulario de contacto y enlaces a redes sociales. |

### 🔹 Características Técnicas

- ✅ Diseño **100% responsivo** (móvil, tablet y escritorio)
- ✅ Tema oscuro con acentos **neón verde** (#00ff66)
- ✅ **Animaciones CSS** suaves (fade-in, slide-up, hover effects)
- ✅ **Modales interactivos** para detalle de ejercicios por músculo
- ✅ **Calculadoras funcionales** con JavaScript puro
- ✅ Navegación con **scroll suave** y menú responsivo
- ✅ Iconos con **Font Awesome 6**
- ✅ Tipografías **Bebas Neue** y **Plus Jakarta Sans** de Google Fonts
- ✅ Imágenes de alta calidad vía **Unsplash**
